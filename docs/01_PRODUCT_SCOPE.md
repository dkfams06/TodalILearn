# 제품 범위와 원칙

상태: Approved (2026-07-17)

## 한 문장 정의

옵시디언에 모아 둔 기독교 영상 대본, 성경 API, Supabase의 예언의 신 자료를 함께 연구하여 연인과 드릴 10~20분 가정예배 설교를 출처와 함께 만드는 개인용 AI 성경연구비서다.

## 해결할 문제

사용자는 설교와 강의 자료를 계속 모으고 있지만, 가정예배를 준비할 때 다음 작업을 수동으로 해야 한다.

- 관련 성경 본문 찾기
- 예언의 신 자료 찾기
- 여러 영상 대본에서 관련 주장과 예화 찾기
- 자료의 근거와 AI의 적용 구분하기
- 연인에게 적절한 묵상형 원고로 재구성하기
- 완성본을 다시 옵시디언에 정리하기

제품은 이 과정을 자동화하되, 사용자가 근거를 확인하고 약 10%를 수정하여 사용할 수 있게 한다.

## 고정된 사용 조건

```text
사용자: 본인 한 명
운영체제: Windows
예배 형태: 가정예배
청중: 연인 두 사람
기본 분량: 약 10분
허용 분량: 10~20분
신학 방향: 성경 중심 + 재림교회 관점 + 예언의 신 보조
작성 목표: AI 초안 90% + 사용자 수정 10%
```

분량, 청중, 설교 유형 선택 UI는 만들지 않는다.

## 자료 정책

### 활용 대상

`05 Raw/bible` 폴더에 있는 모든 Markdown 문서는 활용 가능하다.

- 자료 우선등급을 두지 않는다.
- 정치·사회·역사 성격의 문서도 자동 제외하거나 강등하지 않는다.
- 사용자가 폴더에 보관한 사실을 활용 승인으로 간주한다.
- 검색 순위는 자료 등급이 아니라 입력과의 관련성으로 결정한다.

### 자료 유형 메타데이터

자료 유형은 검색 결과 설명과 활용 위치를 돕기 위해 기록할 수 있다.

```text
sermon
bible_study
devotional
testimony
christian_history
christian_social_commentary
general_christian
```

이 값은 접근 제어, 제외, 고정 가중치에 사용하지 않는다.

### 표현 원칙

- 성경 본문, 자료의 주장, AI의 종합, 관계 적용을 구분한다.
- 사회·역사적 주장은 해당 자료가 말하는 내용으로 추적할 수 있어야 한다.
- AI가 자료에 없는 사실을 원문 주장처럼 만들지 않는다.
- 모든 문서를 사용할 수 있지만 모든 검색에서 억지로 사용할 필요는 없다.
- 관련성이 낮은 자료를 문서 수를 채우기 위해 포함하지 않는다.

## 설교 작성 원칙

1. 성경을 설교의 중심에 둔다.
2. 예언의 신은 성경을 밝히는 자료로 사용한다.
3. 옵시디언 자료는 본문 설명, 관점, 역사, 예화, 적용에 자유롭게 활용한다.
4. 상대를 가르치거나 책망하는 말투를 피한다.
5. `너는`보다 `우리`를 사용한다.
6. 성경을 상대방을 바꾸거나 논쟁에서 이기는 도구로 사용하지 않는다.
7. 개인 적용과 관계 적용을 함께 제시한다.
8. 공적인 강단 설교보다 함께 묵상하는 말투를 사용한다.
9. 한 가지 핵심 진리가 분명히 남게 한다.
10. 직접 인용, 요약, 종합, 적용을 출처 지도에서 구분한다.

## MVP 포함 범위

- Windows에서 옵시디언 입력·출력 폴더 설정
- 전체 Markdown 수동 동기화
- 상대경로와 해시 기반 신규·수정·삭제 감지
- Markdown 원문 Supabase 저장
- 구조화 메타데이터와 청크 생성
- 무료 로컬 임베딩 생성
- 성경 API 조회
- 기존 예언의 신 검색
- 주제 또는 본문 입력
- 관련 자료 자동 선택
- 연구 묶음 생성
- 연인용 가정예배 설교 생성
- 문장 유형과 출처 추적
- 웹 편집과 Supabase 저장
- 옵시디언 Markdown 내보내기

## MVP 이후 범위

- 자동 폴더 감시
- 웹과 옵시디언의 완전한 양방향 동기화
- 여러 PC 동시 수정 충돌 UI
- 설치형 Windows 패키지
- 검색 랭킹 고도화
- 완성 설교 기반 개인 선호 학습
- 모바일 전용 UI

## 명시적 제외 범위

- 교회 공식 설교 작성 플랫폼
- 소그룹 교재와 행사 자료 생성
- 다중 사용자 조직 관리
- 설교자 음성·화법 복제
- 사용자 감정 또는 관계 상태의 장기 프로파일링
- 자동 유튜브 수집 파이프라인

## 성공 기준

1. 모든 입력 Markdown이 중복 없이 동기화된다.
2. 대표 테스트 입력에서 기대 문서가 상위 결과에 나타난다.
3. 성경과 예언의 신 결과는 정확한 위치로 연결된다.
4. 모든 옵시디언 문서는 동일하게 검색·선택될 수 있다.
5. 생성 원고는 연인을 책망하거나 설득하는 어조를 피한다.
6. 근거 문장과 AI 적용을 구분할 수 있다.
7. 기본 약 10분, 필요 시 최대 20분 안에서 자연스럽게 작성된다.
8. 사용자 수정본이 Supabase와 옵시디언에 안전하게 저장된다.
9. 실제 사용 평가에서 대부분이 `조금 수정하면 사용 가능` 이상을 받는다.
