## 범위 결정

선택적 자동 폴더 감시는 이번 MVP에서 보류한다. 사용자가 누르는 수동 동기화는 Sprint 9의 충돌
판정 시점을 예측 가능하게 유지한다. 자동 감시는 실제 문서 추가량이 늘어 수동 실행이 문제가 될 때
별도 Sprint로 진행한다.

Electron/Tauri 패키징도 보류한다. 현재 한 명·메인 PC 한 대 구조에서는 이미 실기기 검증한 Node.js
실행과 Windows 시작프로그램 등록이 가장 단순하게 복구 가능한 방식이다.
