# Sprint 실행계획

상태: Approved (2026-07-17)

## 공통 완료 정의

모든 Sprint는 다음 조건을 만족해야 완료된다.

- 범위 내 구현이 완료됨
- 관련 자동 테스트 통과
- 수동 검증 결과 기록
- 보안 키와 개인 데이터가 로그·Git에 노출되지 않음
- 관련 문서가 실제 구현과 일치함
- 미완료 항목과 기술 부채가 명시됨
- 사용자 확인이 필요한 결과를 사용자에게 검토받음

## Sprint 0 — 설계 승인과 기술 Spike

### 목표

코드를 본격 구현하기 전에 기존 자산과 핵심 기술 결정을 검증한다.

### 작업

- `docs` 전체 사용자 검토 및 수정
- 기존 만나앱 Supabase 실제 테이블·RPC 목록 확인
- `sop_chunks` 행 수, null 벡터 수, 벡터 차원 확인
- 기존 임베딩 생성 경로 확인
- `multilingual-e5-small` Node.js 로컬 실행 Spike
- 한국어 검색어와 샘플 문단 임베딩 속도 측정
- GetBible API 번역본·응답·오류 처리 확인
- Anthropic 모델 설정을 환경변수로 분리할지 결정
- 기존 Supabase 변경 전 백업·복구 방식 결정

### 산출물

- 승인된 계획 문서
- 기술 Spike 결과
- 실제 DB 현황표
- 확정된 임베딩 규격
- Sprint 1 작업 백로그

### 완료 기준

- 무료 로컬 임베딩으로 한국어 유사 문장을 구분할 수 있다.
- 예언의 신 재임베딩 절차가 결정된다.
- 데이터 손실 없이 새 테이블을 추가할 수 있다.
- 미확정 기술 결정이 Sprint 1을 막지 않는다.

## Sprint 3 — 구조화, 청크, 무료 로컬 임베딩

### 목표

모든 문서를 검색 가능한 지식 데이터로 변환한다.

### 작업

- 고정 Markdown 섹션 파서
- 문서 수준 AI 구조화
- 원문 근거가 있는 주장·예화·적용 추출
- 문맥 단위 청크 생성
- 원문 offset 저장
- E5 `passage:` 전처리
- 384차원 임베딩 생성·저장
- 모델·revision·전처리 버전 저장
- 실패 재처리
- 만나앱 `sop_chunks` 5,857개 내보내기
- 새 프로젝트에 원본 행 수·null 수 검증 후 가져오기
- 가져온 `sop_chunks`를 같은 모델로 재임베딩

### 완료 기준

- 7개 문서 구조화 완료
- 모든 청크가 원문 위치로 연결됨
- 옵시디언 청크와 예언의 신 청크가 같은 임베딩 규격 사용
- 새 프로젝트의 `sop_chunks` 원본 행 수가 5,857개와 일치
- 임베딩 누락과 차원 불일치 0건
- 재처리 시 이전 버전과 구분 가능

### 완료 기록 — 2026-07-18

- 옵시디언 7개를 `claude-sonnet-5`로 구조화하고 원문 근거 offset을 전수 검증했다.
- 옵시디언 청크 189개와 예언의 신 청크 5,857개를 동일한 E5 규격으로 임베딩했다.
- 총 6,046개 벡터의 null과 차원 불일치는 0건이었다.
- 동일 상태 재실행에서 청킹·임베딩·AI 호출이 모두 0건임을 확인했다.
- 상세 실행 결과는 `docs/sprints/SPRINT_03.md`에 기록했다.

## Sprint 10 — 운영 안정화와 Windows 사용성

### 목표

일상적으로 사용할 수 있는 안정적인 MVP를 완성한다.

### 작업

- 선택적 자동 폴더 감시
- 처리 실패 재시도 UI
- 동기화·분석 상태 대시보드
- 모델 최초 다운로드 안내
- 백업·복원 문서
- 성능과 Claude Code 구독 호출 상태 기록
- 전체 회귀 테스트
- Windows 실행 또는 패키징 방식 확정

### 완료 기준

- 신규 문서 추가부터 설교 저장까지 전체 흐름 통과
- T1~T8 회귀 테스트 통과
- 오류 발생 시 사용자 스스로 재시도 가능
- 설치·실행·백업 절차 문서화
- MVP 성공 기준 최종 검토 완료
